# Output Directory

This directory stores outputs generated by the Real-Time Object Detection and Tracking System:

1. **Recorded Videos**: Saved when running with `--save` or `--output <filepath>`.
2. **Captured Frame Screenshots**: Saved whenever you press the `S` key during live preview.

## File Naming Convention
- Screenshots: `screenshot_YYYYMMDD_HHMMSS.jpg`
- Recorded videos: `output_<timestamp>.mp4` (or user-specified output path)
